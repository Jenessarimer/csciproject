# csciproject
Project README:
Grid Visualizer Project(projectCSCI) 
This program was designed to read coordinates and block configuration data from an external file, dynamically calculate grid dimensions, allocate a 2D string array, and render a visual text based map to the console.

Compilation and Execution
1.	Ensure both projectCSCI.cpp and data_proj.txt are in the same working directory
2.	Compile the source code using g++
g++ projectCSCI.cpp -o projectCSCI
3.	Execute the compiled code
./projectCSCI
